workbuddy-cross-border
跨境电商工作台配置、MCP 模板与选品 SOP 的集中存放仓库。
项目定位
本仓库用于沉淀跨境电商日常经营分析工作中的三类可复用资产：
1. 工作台配置 — AI 选品工作台等内部工具的环境配置、数据口径与部署约定。
2. MCP 模板 — 连接 ERP、平台后台、数据源所需的 MCP 服务配置模板（脱敏后存放）。
3. 选品 SOP — 从市场容量判断到上架决策的标准作业流程与判定规则。
目录结构
workbuddy-cross-border/
├── README.md
├── workbench/          # 工作台配置
│   ├── config/         # 环境变量样例、参数配置（不含密钥）
│   └── deploy/         # 部署与同步说明
├── mcp-templates/      # MCP 服务配置模板
│   ├── erp/            # 马帮等 ERP 数据源
│   └── platform/       # 平台侧数据接口
├── sop/                # 选品标准作业流程
│   ├── screening.md    # 硬性筛选与排除规则
│   ├── pricing.md      # 利润测算口径
│   └── shortlist.md    # 复核与上架短名单
└── docs/               # 方法论、口径说明、复盘记录
以上目录为规划结构，随资产逐步落地补充。
工作台配置
约定：
- 配置文件中不写入任何密钥、Token、账号密码，一律使用环境变量占位（如 ${ERP_API_KEY}）。
- 涉及公司数据的文件在提交前需脱敏，或仅保留字段结构与计算逻辑。
- 配置变更需在 commit message 中说明影响范围。
MCP 模板
模板遵循最小权限原则，仅申请完成任务所需的数据读取范围。
// 示例结构，实际以各数据源官方文档为准
{
  "mcpServers": {
    "<server-name>": {
      "command": "<executable>",
      "args": ["<args>"],
      "env": { "API_KEY": "${API_KEY}" }
    }
  }
}

公司禁售品类（自动驳回）
以下品类不在开发范围，命中即驳回，不做后续核价：
- 食品类
- 液体 / 水类
- 植物类
- 个护 / 护肤品类

使用约定
- 本仓库为公开仓库，不得存放任何公司敏感数据、供应商实价、平台账号信息。
- 方法论文档可公开；原始数据与核价明细留在内部系统。
- 提交前自查：是否包含真实供应商名称、真实成本、内部链接。
